# Brain Tumor MRI Classification Using Deep Learning

A research-oriented deep learning project for classifying brain MRI images into three tumor categories using a lightweight Convolutional Neural Network (CNN). The project also includes a Streamlit web application that allows users to upload MRI images and obtain model predictions.

## Project Overview

Brain tumors are associated with different imaging characteristics that can be studied using medical image analysis and deep learning.

This project explores automated classification of brain MRI slices into three categories:

- **Meningioma**
- **Glioma**
- **Pituitary Tumor**

A custom CNN architecture was developed using PyTorch. The model processes grayscale MRI images and produces class scores for the three tumor categories.

The project also provides a simple web interface built with Streamlit for interactive image classification.

**Project Type:** Medical Image Classification / Deep Learning  
**Framework:** PyTorch  
**Programming Language:** Python  
**Web Application:** Streamlit  
**Evaluation Strategy:** Patient-level grouped evaluation

## Objectives

- Develop a lightweight CNN for brain tumor MRI classification.
- Perform image preprocessing and dataset analysis.
- Prevent patient-level data leakage through grouped data partitioning.
- Evaluate classification performance using multiple metrics.
- Analyze class-wise performance and classification errors.
- Build a web application for uploading MRI images and generating predictions.

## Dataset

This project uses the **Brain Tumor MRI Dataset** introduced by Jun Cheng and colleagues.

**Dataset source:**  
https://doi.org/10.6084/m9.figshare.1512427

Dataset characteristics:

| Property | Description |
|---|---|
| Total MRI images | 3,064 |
| Unique patients | 233 |
| Image modality | T1-weighted contrast-enhanced MRI |
| Number of classes | 3 |
| Image format | MATLAB `.mat` files |
| Image input size | 224 × 224 |
| Number of folds | 5 |

### Class Distribution

| Tumor Category | Number of Images |
|---|---:|
| Meningioma | 708 |
| Glioma | 1,426 |
| Pituitary Tumor | 930 |
| **Total** | **3,064** |

The dataset contains multiple MRI slices from individual patients. Therefore, patient-level grouping was used to prevent images from the same patient appearing in different data partitions.

**Note:** The original dataset and processed image arrays are not included in this GitHub repository. Refer to the original dataset source for access.

## Data Preprocessing

The MRI images underwent the following preprocessing steps:

1. Loading MRI images from MATLAB files.
2. Converting images into grayscale representations.
3. Resizing images to 224 × 224 pixels.
4. Applying per-image min-max normalization.
5. Organizing image labels and patient identifiers.
6. Creating patient-grouped evaluation partitions.

The normalized image values were scaled between 0 and 1.

## Model Architecture

A custom lightweight Convolutional Neural Network was implemented using PyTorch.

### Architecture Components

- Convolutional layers
- Batch normalization
- ReLU activation
- Max pooling
- Adaptive average pooling
- Fully connected layers
- Dropout regularization
- Three-class output layer

**Total trainable parameters:** 25,699

### Training Configuration

| Parameter | Configuration |
|---|---|
| Framework | PyTorch |
| Optimizer | Adam |
| Learning rate | 0.001 |
| Loss function | Weighted Cross-Entropy Loss |
| Batch size | 4 |
| Training epochs | 2 per fold |
| Input dimensions | 224 × 224 |
| Execution device | CPU |

Class-weighted loss was used to address differences in class distribution.

## Evaluation Methodology

The dataset was partitioned into five patient-level folds using the official `cvind.mat` partition file.

Fold 1 was reserved for model development. The final held-out evaluation used Folds 2–5, with predictions generated by separate fold-specific models.

This is a grouped multi-fold evaluation, not a claim of full five-fold cross-validation.

### Evaluation Metrics

- Accuracy
- Balanced Accuracy
- Macro F1-score
- Precision
- Recall
- Confusion Matrix

### Held-Out Evaluation Results

The following results represent pooled predictions across Folds 2–5.

| Metric | Result |
|---|---:|
| Accuracy | 65.98% |
| Balanced Accuracy | 65.99% |
| Macro F1-score | 65.55% |

**Evaluation coverage:** 2,522 MRI slices from 188 unique patients.

### Class-wise Performance

| Class | Precision | Recall | F1-score |
|---|---:|---:|---:|
| Meningioma | 41.45% | 70.81% | 52.29% |
| Glioma | 79.56% | 67.57% | 73.08% |
| Pituitary | 88.62% | 59.60% | 71.27% |

The results demonstrate variation in classification performance across tumor categories and evaluation folds. Meningioma-related misclassifications were a notable challenge.

These results should be interpreted as experimental research findings rather than evidence of clinical performance.

## Streamlit Web Application

- Upload an MRI image.
- Analyze the uploaded image using the trained CNN.
- Display the predicted tumor category.
- Display model softmax scores for all three classes.

- TIFF

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/Brain-Tumor-MRI-Classification.git
```

**2. Navigate to the project directory**

```bash
cd Brain-Tumor-MRI-Classification
```

**3. Create and activate a Conda environment (recommended)**

```bash

conda activate medical_imaging
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Run the application**

```bash
python -m streamlit run app.py
```

The application will open in your browser, usually at:

```text
http://localhost:8501
```

**Important:** The trained model checkpoint must be available in the expected `models/` directory for the application to run.

## Limitations and Disclaimer

This project is intended strictly for educational and research purposes.

- The classifier recognizes only three tumor categories: Meningioma, Glioma, and Pituitary Tumor.
- There is no normal or no-tumor class.
- The model always selects one of its three available classes, even for normal or unsuitable images.
- The model was developed using 2D T1-weighted contrast-enhanced MRI slices.
- Images with different acquisition protocols, orientations, modalities, or contrast characteristics may produce unreliable predictions.
- DICOM input is not currently supported.
- Softmax scores are model outputs, not clinically calibrated probabilities.
- The model has not undergone clinical validation.

**This application is not a medical diagnostic system. Its predictions must not be used for medical decisions, treatment selection, or patient management. Always consult qualified medical professionals.**
